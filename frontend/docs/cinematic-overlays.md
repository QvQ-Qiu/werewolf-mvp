# 对局过场与技能弹窗 · 产品规格（v1）

## 目标

在暖调暗黑叙事 UI 上，用**短过场**建立昼夜节奏感，用**身份揭示**强化开局仪式感，用**技能弹窗**集中夜晚私域操作，避免与公屏、座位列争抢注意力。

## 1. 昼夜过场（Phase Transition）

| 触发 | 表现 | 时长 |
|------|------|------|
| `PHASE_CHANGED` → `night` | 全屏暗幕 + 「夜幕降临 · 第 N 夜」 | ~2.4s 自动消失 |
| `PHASE_CHANGED` → `day`（且 N≥1） | 暖光晕 + 「天亮了 · 第 N 日」 | ~2.4s 自动消失 |
| `setup` / `game_over` | 不播 | — |

- 不阻塞操作（`pointer-events: none`），仅视觉层。
- 重连快照：若首帧即为 night/day，不补播（避免刷屏）。
- `prefers-reduced-motion`：缩短为 0.4s 淡入淡出。

## 2. 身份揭示（Role Reveal）

| 触发 | 表现 |
|------|------|
| `GAME_STARTED` 且本地未确认过本局 | 居中面板：座位号 + 角色名 + 一句职责提示 +「进入议事厅」 |

- 每局 `gameId` 仅展示一次（`sessionStorage`）。
- 必须点击确认后才关闭；过场队列在其后播放。

## 3. 技能弹窗（Skill Modal）

| 触发 | 表现 |
|------|------|
| `NIGHT_ACTION_REQUEST` 且轮到你、仍存活 | 模态层：标题按 `action_type`，目标选择 + 确认/跳过 |

- 狼刀 / 验人 / 女巫 / 守卫 / 猎人开枪 分文案。
- 发言、投票仍在底部操作坞；夜晚技能**仅弹窗**，不再挤占 dock。
- 观战或已出局：不弹窗。

## 4. 结算过场（Game Result）

| 条件 | 表现 |
|------|------|
| `GAME_END` | 全屏遮罩；按身份与阵营胜负显示 **胜利** 或 **败北** |
| 胜利 | 暖金晕光 + 标题微光 |
| 败北 | 暗幕 + 灰褐标题 |

## 5. 非目标（本版）

- 全屏视频、3D、复杂粒子。
- 其他玩家技能过程的公屏动画（仅自己弹窗）。

## 6. 验收

- [ ] 公屏滚动条为暖色细条，不破坏叙事风格。
- [ ] 入夜/天亮有过场，且左右座位不随公屏滚动。
- [ ] 开局见身份卡，确认后进入对局。
- [ ] 夜晚轮到自己时弹窗操作，关闭后 dock 无重复夜晚块。
- [ ] 对局结束显示胜/败结算动画，狼人/好人身份判断正确。
